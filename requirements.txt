# Instalación: pip install -r requirements.txt
#
# O usando extras (definidos en setup.py):
#   pip install bluesky[full]    # BLE + Web + todo
#   pip install bluesky[web]     # Solo web dashboard
#   pip install bluesky[ble]     # Solo Bluetooth LE
#   pip install bluesky[dev]     # Desarrollo
#
# Todas las dependencias listadas se usan directamente por el código:
#   rich        → CLI, consola REPL y modo educativo (bluesky/cli.py, console.py)
#   pyserial    → shell RFCOMM e inyección AT (modules/exploits, bluebugging)
#   flask       → dashboard web (bluesky/web/app.py)
#   bleak       → escaneo BLE cross-platform (device_scanner, blueborne, btspam)
#   scapy       → packet crafting (KNOB, BLUFFS, SweynTooth, Crackle, ...)
#   cryptography→ cifrados BLE (crackle)
#   pytest*     → suite de tests offline (tests/)
